# CampusBite Canteen System

A C-based software project designed to manage canteen orders, calculate bills with member discounts, and analyze item statistics and grid data.

## Features:
- **Bill Calculation:** Calculates subtotal and final discounted bills based on meal/drink quantities and membership status.
- **Order Statistics:** Finds maximum orders and counts items meeting target thresholds.
- **String Manipulation:** Counts vowels and underscores, and normalizes item names (converts to uppercase and replaces underscores with spaces).
- **Matrix/Grid Analysis:** Computes row maximums, column maximums, and counts zero values in grid layouts.
